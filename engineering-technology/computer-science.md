# Computer Science

## Overview

Computer science is the study of computation, information, and automation. It spans theoretical disciplines (algorithms, computability, complexity) to applied disciplines (software engineering, AI, networking). It is foundational to modern technology and increasingly to all scientific disciplines.

## Core Concepts

### Algorithms & Data Structures
- **Data Structures**: Arrays, linked lists, stacks, queues, hash tables, trees (binary, B-tree, trie), graphs, heaps
- **Algorithm Design**: Divide and conquer, dynamic programming, greedy, backtracking, branch and bound
- **Sorting**: Quicksort, mergesort, heapsort, radix sort; O(n log n) lower bound for comparison sorts
- **Searching**: Binary search, BFS, DFS, Dijkstra, A*, Bellman-Ford
- **Complexity Theory**: Big-O notation; P vs NP; NP-complete problems; polynomial-time reductions
- **Recursion**: Base case, recursive case; memoization; tail recursion

### Programming
- **Paradigms**: Procedural, object-oriented, functional, declarative, concurrent
- **Type Systems**: Static vs dynamic; strong vs weak; generics; type inference
- **Memory Management**: Stack vs heap; garbage collection; manual allocation (C/C++)
- **Concurrency**: Threads, mutexes, semaphores, deadlocks; async/await; actor model
- **Languages**: C, C++, Java, Python, JavaScript, Rust, Go, Haskell, SQL, Assembly

### Computer Architecture
- **Von Neumann Architecture**: CPU (ALU + control unit), memory, I/O
- **Instruction Set**: CISC vs RISC; x86, ARM, RISC-V
- **Pipelining**: Instruction-level parallelism; hazards
- **Memory Hierarchy**: Registers → L1/L2/L3 cache → RAM → SSD/HDD
- **Parallel Computing**: Multi-core, GPU computing, SIMD, MIMD
- **Quantum Computing**: Qubits, superposition, entanglement; quantum algorithms (Shor, Grover)

### Operating Systems
- **Process Management**: Scheduling (round-robin, priority, MLFQ); process vs thread
- **Memory Management**: Virtual memory; paging; segmentation; page replacement algorithms
- **File Systems**: Inodes, directories, journaling; FAT, NTFS, ext4, APFS
- **Synchronization**: Mutexes, semaphores, monitors, condition variables
- **I/O**: Interrupts, DMA, device drivers

### Networking
- **OSI Model**: 7 layers (physical through application)
- **TCP/IP**: TCP (reliable, ordered), UDP (fast, unreliable); IP addressing, routing
- **HTTP/HTTPS**: Request-response; REST; status codes; TLS/SSL
- **DNS**: Domain name resolution; hierarchical naming
- **Routing**: BGP, OSPF, RIP; routing tables
- **Network Security**: Firewalls, VPNs, intrusion detection

### Databases
- **Relational Model**: Tables, keys, normalization (1NF-BCNF); SQL
- **NoSQL**: Document (MongoDB), key-value (Redis), column-family (Cassandra), graph (Neo4j)
- **Transactions**: ACID properties; isolation levels; two-phase commit
- **Indexing**: B-trees, hash indexes; query optimization
- **Distributed Databases**: CAP theorem; eventual consistency; sharding, replication

### Artificial Intelligence & Machine Learning
- **Machine Learning**: Supervised (regression, classification), unsupervised (clustering, dimensionality reduction), reinforcement learning
- **Deep Learning**: Neural networks, CNNs, RNNs/LSTMs, transformers, attention mechanisms
- **NLP**: Tokenization, embeddings, language models, sentiment analysis, machine translation
- **Computer Vision**: Image classification, object detection, segmentation
- **Robotics**: Perception, planning, control; SLAM
- **Generative AI**: GANs, VAEs, diffusion models, large language models

### Software Engineering
- **SDLC**: Requirements → design → implementation → testing → deployment → maintenance
- **Design Patterns**: Singleton, factory, observer, strategy, decorator
- **Version Control**: Git; branching, merging, rebasing
- **Testing**: Unit, integration, end-to-end; TDD; code coverage
- **Agile/Scrum**: Iterative development; sprints; retrospectives
- **DevOps**: CI/CD; containerization (Docker); orchestration (Kubernetes); IaC
- **Distributed Systems**: Microservices, message queues, consensus (Raft, Paxos)

### Theory of Computation
- **Automata Theory**: Finite automata, pushdown automata, Turing machines
- **Computability**: Halting problem; Church-Turing thesis; decidable vs undecidable
- **Formal Languages**: Regular, context-free, context-sensitive, recursively enumerable
- **Information Theory**: Shannon entropy; channel capacity; data compression

## Key Theories

| Theory | Description |
|--------|-------------|
| Church-Turing Thesis | Anything computable is computable by a Turing machine |
| P vs NP | Can every problem whose solution is quickly verified also be quickly solved? |
| CAP Theorem | Distributed systems can have at most 2 of: consistency, availability, partition tolerance |
| Shannon's Information Theory | Mathematical framework for communication and data compression |
